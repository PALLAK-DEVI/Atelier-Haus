# ATELIER HAUS — Luxury Architecture & Interior Design Studio

An ultra-luxury, single-page web application re-branded as **Atelier Haus**.

## Updates in this Version

1. **Rebranded to ATELIER HAUS**: Updated all branding elements across headers, navigation, footer, studio text, and contact forms.
2. **6-Slide Hero Gallery**: Expanded from 3 to 6 high-resolution architectural images.
3. **Manual Carousel Navigation**: Added instant Next/Previous arrows (`<` / `>`) and interactive indicators that instantly cycle through slides.
4. **Auto-Rotate Reset**: Manual navigation automatically pauses and restarts the 6-second auto-play timer for a smooth user experience.

## File Structure

- `index.html`: Complete, self-contained single-page website.
- `README.md`: Project summary and change log.
